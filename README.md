# Antigravity ワークショップ Web アプリ (`agy-ws-webapp`)

Google Antigravity ハンズオン用の Next.js + Tailwind CSS ベースアプリケーションです。

## 📖 ハンズオン Codelab（手順書・プロンプト集）

ハンズオンの詳細手順やコピペ用プロンプト集は、以下の Codelab ページをご覧ください：
👉 **[Antigravity ハンズオン Codelab](https://tichiba.github.io/agy-ws-webapp/)**

---

## 🚀 クイックスタート

### 1. 依存関係のインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

---

## 🛠️ 技術スタック
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
