Google Antigravity ハンズオンへようこそ！

本ハンズオンでは、Google の次世代 AI エージェント開発プラットフォーム Google Antigravity を使って、Web アプリケーションの開発フローを実践的に体験します。

🎯 このハンズオンで体験すること:
  • コンテキスト理解: リポジトリ全体を読み解かせるチャット操作
  • 計画的な実装: いきなりコードを書かせず「まず計画を立案・レビュー」させてから実装
  • /grill-me コマンド: エージェントからの逆質問で仕様を詰める対話体験
  • AGENTS.md: プロジェクト固有のルールを定義してエージェントを自律制御

事前準備

  1. Antigravity を起動し、Google Cloud Project に接続されていることを確認します。
  2. ハンズオン用のベースリポジトリを取得します。
    お使いの環境に合わせて、【方法A: Git を利用】 または 【方法B: ZIP をダウンロード（Git 不要）】 のいずれかの手順でソースコードを取得してください。

    ▼ 方法A: Git を利用する場合

    ターミナルで以下のコマンドを実行し、リポジトリをクローンします：

    Terminal
    git clone https://github.com/tichiba/agy-ws-webapp.git

    ▼ 方法B: ZIP をダウンロードする場合（Git 未インストールの方）

    1. ZIP のダウンロード:
    以下のリンクをクリックして ZIP ファイルをダウンロードします：
    👉 https://github.com/tichiba/agy-ws-webapp/archive/refs/heads/main.zip

    2. ZIP の解凍:
    ダウンロードした agy-ws-webapp-main.zip を任意のフォルダ（デスクトップなど）に解凍（展開）します。

  3. Antigravity でプロジェクトフォルダを開く（方法A・B共通）:
    Antigravity のメニュー File -> Open Folder から、取得したプロジェクトフォルダを開きます：
    • 方法Aの場合: クローンした agy-ws-webapp フォルダ
    • 方法Bの場合: 解凍した agy-ws-webapp-main フォルダ

Step 1: プロジェクトの把握（所要時間: 5分）

まずは Antigravity のエージェントにリポジトリ全体の構造を解説させ、その後に依存パッケージをインストールしてベースアプリを起動し、画面を確認しましょう。

1. エージェントにコード構成を解説させる

右側の Antigravity チャットパネルに以下のプロンプトを入力して送信します。

Antigravity Chat Prompt
このアプリの全体構成、主要コンポーネントの役割、ルーティングの仕組みをわかりやすく箇条書きで教えて
💡 ポイント: Antigravity は個別のファイルを指定しなくても、プロジェクト全体を自動インデックスして構造を正確に把握します。

2. 依存パッケージのインストール

コードの全体像を把握できたら、アプリを動かすための依存パッケージをインストールします。
Cmd + Shift + P（Windows / Linux は Ctrl + Shift + P）を押してコマンドパレットを開き、Terminal と入力して候補に出てくる View: Toggle Terminal（または Terminal）を選んでターミナルを開きます（ショートカット Ctrl + ` でも開閉できます）。
開いたターミナルで以下のコマンドを実行します：

Terminal
npm install

もしくは、エージェントに「npm install を実行して」とチャットで指示してターミナルコマンドを実行させることも可能です。

3. 開発サーバーの起動

ターミナルで以下のコマンドを実行して開発サーバーを起動します。

Terminal
npm run dev

もしくは、エージェントに「開発サーバーを起動して」とチャットで指示して npm run dev コマンドを実行させることも可能です。

ブラウザで http://localhost:3000 を開き、初期画面が表示されることを確認します。

Step 2: 計画的な機能実装（所要時間: 7分）

AI コーディングで重要なのは、いきなりコードを書かせるのではなく「まず計画を立てさせ、それを人間が確認して承認する」ことです。

1. 実装計画の立案

チャットパネルに以下のプロンプトを入力し、まずはタスク管理機能の設計・実装計画を提案させます。

Antigravity Chat Prompt
このアプリにシンプルなタスク管理機能を追加したいです。 - タスクの追加（タイトル入力） - タスクの一覧表示 - タスクの削除 - ステータス（未着手 / 進行中 / 完了）の保持 いきなりコードを書かず、まずはデータ構造とコンポーネント構成の実装計画を箇条書きで提案してください。

2. 計画の承認と実装指示

エージェントが提示した計画を確認し、問題なければ計画画面に表示される 「Proceed」 ボタンをクリックするか、チャットで一言送信するだけで実装が始まります（どのファイルを作成・更新するかを人間が指定する必要はありません）。

Antigravity Chat Prompt（または「Proceed」ボタンを押す）
この計画で実装を進めてください。
💡 ポイント: エージェントが承認された計画に沿って自律的に必要なファイルの作成やコードの更新を行います。生成された差分（Diff）を確認し、Accept を押して適用しましょう。

Step 3: /grill-me による仕様対話とモダンUI化（所要時間: 8分）

要件が曖昧なとき、エージェント側から質問を投げさせて仕様を具体化する /grill-me コマンドを体験します。

1. 仕様対話の開始 (/grill-me)

チャットパネルに以下を入力します。

Antigravity Chat Prompt
/grill-me タスク一覧画面に「ステータス別の絞り込みフィルター（タブ）」と「ワンクリックでステータスを変更できるボタン」を追加したいです。

2. 質問への回答とデザインの指示

エージェントからいくつか質問が返ってきます。簡単な回答とともに、Tailwind CSS でのモダンなデザイン適用を指示します。

Antigravity Chat Prompt
上記の回答内容で実装してください。あわせて、背景に柔らかなグラデーション（indigo〜sky）、半透明のすりガラスカード（backdrop-blur bg-white/80）、ホバー時の浮き上がりアニメーションを取り入れた華やかなモダンUIに整えてください。

3. ブラウザで動作確認

http://localhost:3000 を開き、以下を確認します：

  • 新規タスクを追加できるか
  • ステータス（未着手・進行中・完了）を変更できるか
  • フィルタータブで正しく絞り込みができるか
  • グラデーションやすりガラス効果が適用されているか
💡 ポイント: もし画面で動かない部分やレイアウト崩れがあれば、「〇〇が動かないので直して」とチャットにそのまま投げてみましょう！

Step 4: AGENTS.md による開発ルールと自己検証（所要時間: 5分）

AI エージェントは優秀ですが、プロジェクト固有の「テスト/ビルドコマンド」や「絶対にやってはいけないこと」を事前には知りません。
最初から膨大なルールを書くのではなく、「プロジェクト概要」「必須の検証コマンド」「禁止事項3つ」の最小構成（約30行）で小さく始めるのがベストプラクティスです。

1. 最小構成の AGENTS.md の作成指示

チャットパネルに以下を入力し、プロジェクトルートにスターター設定の AGENTS.md を作成させます。

Antigravity Chat Prompt
プロジェクトのルートに、以下の内容で AGENTS.md を作成してください。 # AI エージェント作業ガイドライン 本プロジェクトで作業する AI エージェントは、以下のルールに従ってください。 ## 1. プロジェクト概要 * **概要:** Antigravity ワークショップ用 Next.js + Tailwind CSS タスク管理アプリ * **主要ディレクトリ:** `src/app/` (UI・画面実装) ## 2. 必須の検証コマンド（完了前に必ず自己実行すること） コードを変更・追加した後は、完了報告の前に必ず以下のコマンドを実行してエラーがないことを確認してください。 * **ビルド / 型チェック:** `npm run build` * **リント:** `npm run lint` ## 3. 絶対にしてほしくないこと 3 つ（禁止事項） 1. **シークレットの直接記述禁止:** API キーやパスワード、トークンをコード内にハードコードしないこと。 2. **破壊的コマンドの禁止:** `git reset --hard` や `git push --force` などの破壊的 Git 操作は絶対に実行しないこと。 3. **未検証での完了報告禁止:** ビルドや型チェックがエラーのまま完了と報告せず、自律的に修復してから完了とすること。 --- ## 4. チーム固有の追加ルール

2. 自己検証（Self-Verification）の効果を試す

AGENTS.md が作成されたら、普通の言葉で追加機能を依頼してみましょう。

Antigravity Chat Prompt
タスク一覧の上に「タスクのキーワード検索バー」を追加してください。
💡 ポイント（自律的な自己検証）:
プロンプトに「AGENTS.md を読んで」や「ビルドを実行して」と一切指定していませんが、Antigravity は自動的に AGENTS.md を認識します。コード編集後、自律的に npm run build や npm run lint を実行し、エラーがないことを確認してから完了報告します。

3. ルールを「1 行追記して育てる」体験

開発を進める中で、「コンポーネントを 1 ファイルにベタ書きせず分割してほしい」「アイコンは勝手に追加せず既存ライブラリを使ってほしい」といったチーム方針が出てきた場合、プロンプトで毎回指示するのではなく、AGENTS.md の 「4. チーム固有の追加ルール」 に 1 行追記してエージェントを育てていきます。

Antigravity Chat Prompt
AGENTS.md の「4. チーム固有の追加ルール」に以下のルールを追記してください： * 新しいUI部品を作成する際は page.tsx に直書きせず、src/components/ 配下にコンポーネントファイルとして分割すること（理由: 可読性と再利用性を保つため）。 * アイコンを使用する際は、外部パッケージを新規インストールせず必ず既存の lucide-react を使用すること。 追記後、各タスクに「優先度（高・中・低）」を設定・表示するバッジ機能を追加してください。
💡 ポイント:
エージェントが AGENTS.md の追記ルールに従い、自動的に src/components/ 配下に独立したコンポーネントファイルを作成し、lucide-react のアイコンを使って実装することを確認します。
